# 欢迎使用这个博客框架

这是一个**纯静态**、支持 Markdown 的博客框架,无需任何构建工具,可以直接部署到 GitHub Pages。

## 特点

- ✍️ 用 Markdown 写文章,浏览器实时渲染
- 🎨 现代卡片式设计,支持明暗主题切换
- 🔍 内置文章搜索和标签筛选
- 💡 代码块自动高亮
- 📱 响应式布局,手机电脑都好看
- 🚀 零构建,push 到 GitHub 即可访问

## 如何添加一篇新文章

只需要两步:

### 第一步:写文章

在 `posts/` 目录下新建一个 Markdown 文件,比如 `my-first-post.md`,然后写下你的内容。

### 第二步:登记文章

打开根目录的 `posts.json`,在数组里添加一条记录:

```json
{
  "slug": "my-first-post",
  "title": "我的第一篇文章",
  "date": "2026-09-28",
  "excerpt": "这里写一段文章摘要,会显示在首页卡片上。",
  "tags": ["随笔"],
  "cover": ""
}
```

> **注意**:`slug` 必须和文件名一致(不含 `.md` 后缀)。

保存后刷新页面就能看到新文章啦!

## 自定义站点信息

编辑根目录的 `config.js`,可以修改站点标题、作者、页脚等信息。
